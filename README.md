# knowbel.github.io

The website for [Knowbel Reader](https://github.com/knowbel/knowbel-reader),
served by GitHub Pages at <https://knowbel.github.io>.

It's a single static page (`index.html` and `style.css`) with no build step.
Screenshots live in `images/` and were taken from the app with public-domain
books from Project Gutenberg.
